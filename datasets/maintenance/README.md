# 설비 정비 합성 데이터 (35장)

같은 엔진을 세 번째 도메인에 쓸 수 있는지 확인하려고 만든 작은 합성 데이터입니다.
공장 두 라인(A·B)의 설비 40대, 정비원 8명(라인마다 팀장 1명), 작업 지시 60건으로 이뤄져 있습니다.
실제 회사·인물과 무관하며, 기준일은 2027-01-18 입니다.

| 테이블 | 행 | 내용 |
|---|---|---|
| `technicians` | 8 | 정비원: 라인, 직책(정비팀장·정비원), 기술(전기·기계), 동시에 맡을 수 있는 작업 수 |
| `equipment` | 40 | 설비: 라인, 중요도(상·중·하), 상태(가동·정지·폐기), 점검 주기, 마지막 점검일, 담당 정비원 |
| `work_orders` | 60 | 작업 지시: 예방점검·고장수리, 상태(접수→배정→작업중→완료, 취소), 예상 비용 |

```bash
bash scripts/load_maintenance.sh      # 실행 중인 컨테이너에 (다시) 적재
```

`.env` 에 `MAINTENANCE_DATABASE_URL` 을 추가합니다 (다른 DB URL 과 같은 형식, DB 이름만 `maintenance`).
